# 讯集 0.7.0

现代、轻量的 Android 本地网站聚合应用。无账号、无云服务器，所有订阅和文章记录保存于手机。支持 Android 8.0 及以上。

## 使用

1. 打开应用，点击添加网站，输入**公告列表、博客主页、说说/动态栏目或 RSS/Atom 地址**，名称留空时自动读取网站元数据或标题；图标自动获取，无法获取时显示文字头像。
2. 首次会导入首页/订阅源上的已有公告（不发送大量历史通知）。点击卡片优先在应用内阅读正文；选择“原网页”切换到嵌入的原网站，使用网站本身的点赞、评论和登录等功能。无法提取正文时自动切换至应用内网页；外部浏览器入口仍保留。部分网站限制 WebView 或第三方登录，无法保证所有互动系统可用。
3. 默认每小时自动检查，设置中可调整为 15、30 分钟、1、3、6 小时。开启系统通知权限才能收到通知。
4. 后台检查时间由 Android 调度，省电、系统后台限制、强行停止应用、断网可能推迟或暂停更新。可手动刷新。
5. 信息流左上角打开“我的关注”侧边栏，选择全部信息或某个网站，查看该来源的未读数及独立信息流。公开版默认没有预置订阅；升级时保留设备上已有的数据与设置。
6. 博客主页同时识别可公开抓取的短动态和 RSS 文章；支持常见的说说、微动态页面结构（包括 Sakurairo 的说说卡片）。独立动态栏目可以单独订阅。首次识别历史说说不发送历史通知；图片或媒体动态可点击原文查看。
7. 启动时自动检查新版本（成功检查间隔至少 6 小时），有更新弹出提示；设置中也可手动检查。下载时校验版本、文件大小、可用的 SHA-256 和现有应用签名，通过独立 Android PackageInstaller 会话交给系统安装；安卓系统会要求安装授权与确认，不静默安装。
8. 设置 → 云同步：支持坚果云、Nextcloud/ownCloud 与通用 HTTPS WebDAV。先在云端建立可写文件夹（坚果云创建 Xunji 文件夹，使用第三方应用密码），填写地址、账号及应用密码，点击立即同步。可选启动时自动同步。订阅、历史和已读状态在设备间合并；支持订阅删除同步。凭据由 Android Keystore 加密，仅保存在设备上，不上传云端同步文件。同步文件存放在所选 WebDAV 文件夹中的 `Xunji-sync-v1.json`，请保护云端账号。其他服务如百度网盘暂无专用 API 适配。
9. 支持正文外的公开附件列表（包括常见 CMS 下载链接）、PDF 预览和图片分页预览。PDF 阅读设置支持连续滚动或逐页阅读、适应宽度或整页显示，双指缩放、页码跳转及保存原文件；设置在本机记忆。预览前验证实际 PDF 内容，支持常见压缩响应和明确的同源公开 PDF 链接，区分网络与文件错误。受保护、损坏或系统不兼容的文件仍可能不能预览，已下载的有效 PDF 可以保存。纯净阅读去除无内容的空段落、保留落款对齐，并允许横向查看宽表格。
10. 在订阅卡片中点击网站图标或“更多 → 自定义网站图标”，可以从相册选择图片，拖动与缩放裁剪成正方形，确认预览后保存，也可恢复自动图标；自定义图标仅保存在本机。升级后旧版登录订阅将停用并从界面隐藏，旧数据保留在设备上且不参与公开订阅的更新及云同步。
11. 信息流顶部的放大镜可搜索本地已收录的标题、摘要、网站名称和域名，支持多关键词、中文及英文大小写不敏感搜索，可切换全部订阅或指定网站；点击结果进入原有应用内阅读。搜索无需联网，不会额外抓取网页正文。

## 范围

适合公开且无需登录的静态公告列表或 RSS/Atom。涉及 JavaScript 渲染、验证码、登录或不规则网页结构的来源可能抓取不到或误识别。建议检查订阅状态并在首次添加后验证抓取内容；不要把它作为考试重要截止时间的唯一信息来源。不会绕过访问限制。每次最多读取一个列表页上的 70 条信息，最多订阅 30 个来源。

## 构建

需要 JDK 17+、Android SDK platform 35、build-tools 35.0.0、zip、curl 和 sha256sum。构建脚本会自动下载并校验固定版本的 Jsoup 依赖。示例：

```bash
export ANDROID_JAR="$ANDROID_HOME/platforms/android-35/android.jar"
export BUILD_TOOLS="$ANDROID_HOME/build-tools/35.0.0"
bash build.sh
```

APK 产物为 `out/Xunji-0.7.0.apk`。项目使用原生 Android Java UI、Jsoup 1.18.3（MIT License）和 JobScheduler。

正式更新请在 GitHub Releases 发布形如 `v0.4.0` 的正式标签，并上传同版本的 `Xunji-0.4.0.apk`。必须使用已有安装包的同一原始签名密钥，并递增 versionCode；否则设备拒绝更新。

**签名说明：** 仓库不包含原始 `local-dev.keystore` 或其他签名密钥。若需要覆盖安装之前的版本，请将自己安全备份的原始 `local-dev.keystore` 放在项目根目录；否则构建会生成新的本地开发签名，不能直接覆盖旧签名的安装包。正式发布应采用独立安全的签名方案。
